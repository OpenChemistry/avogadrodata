# gemmi test data

Files used by the gemmi third-party library test in avogadrolibs
(`tests/io/gemmitest.cpp`). Copied from the `tests/` directory of
https://github.com/project-gemmi/gemmi:

- `5i55.cif`: mmCIF coordinates of PDB entry 5I55
- `5i55_tiny.ccp4`: a small CCP4 map (8 x 6 x 10 grid) derived from 5I55
- `5wkd_phases.mtz`: MTZ file with map coefficients for PDB entry 5WKD
  (gunzipped from `5wkd_phases.mtz.gz`)

The Protein Data Bank archive is public domain (CC0).
