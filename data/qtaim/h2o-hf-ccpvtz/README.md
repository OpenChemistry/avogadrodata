# H2O HF/cc-pVTZ (ORCA), spherical f functions

The water molecule of `../h2o-hf-631gd/` (`geometry.xyz`, same fixed
geometry) with ORCA 6.1.0, restricted Hartree-Fock and the cc-pVTZ basis
(spherical d and f). `orca-hf-cc-pvtz/h2o.molden` was written by `orca_2mkl`.
`points.xyz` holds the same 20 comparison points as `../h2o-hf-631gd/`.

`reference-points.json` has the density and derivatives from critic2 1.4.306
at those points, from the Molden file with critic2's `orca` dialect; same
layout and units as in `../h2o-hf-631gd/README.md`. It is generated by
`../h2o-hf-631gd/make_reference_points.py`.

Used to test the ORCA f-shell conventions of the Molden reader. No program
logs are included.
