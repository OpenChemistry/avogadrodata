# N2 B3LYP/cc-pVQZ (ORCA), spherical g functions

N2 at a fixed geometry (`geometry.xyz`, Angstrom) with ORCA 6.1.0, restricted
B3LYP and the cc-pVQZ basis (spherical d, f and g).
`orca-b3lyp-cc-pvqz/n2.molden` was written by `orca_2mkl`. `points.xyz` holds
20 comparison points (Angstrom, same frame): 1 bond midpoint, 15 valence
region points and 4 tail points.

`reference-points.json` has the density and derivatives from critic2 1.4.306
at those points, from the Molden file with critic2's `orca` dialect; same
layout and units as in `../h2o-hf-631gd/README.md`. It is generated by
`../h2o-hf-631gd/make_reference_points.py`.

Used to test the ORCA g-shell conventions of the Molden reader. No program
logs are included.
