# Bond order perception corpus

Test molecules for `Molecule::perceiveBondOrders()` in avogadrolibs, read by
`tests/io/bondorderscorpustest.cpp` (and by `tests/core/` for the inline
cases). Every file has 3D coordinates, explicit bonds and, except for the
carbon cages and nanotubes, the correct Kekule bond orders. The test sets all
bond orders to 1, runs perception, and compares the result with the file.

Two comparisons are made. The first is that every atom ends with the order
sum of the reference. The second ("strict") is ring level: for every ring of
the reference whose bonds alternate single and multiple, the result must have
the same number of multiple bonds in that ring, and every bond that is in no
ring must have exactly the reference order. Fused aromatic systems have
several valid Kekule structures, so a few files fail the strict check even
though the answer is chemically fine.

`known-failures.txt` lists the files (and charge mode) perception is expected
not to get right, with a reason. The test requires everything else to pass,
requires the listed failures to fail cleanly, and only reports a listed file
that unexpectedly passes.

### CCD selection

About 100 components were chosen by hand (nucleotides and bases, the
cofactors FAD, FMN, NAD, NAP, SAM, PLP, TPP, COA, HEM, CLA, drugs such as
STI, amino acids, sugars). The rest is a seeded random sample of the CCD
(seed 20261022) of components with 6 to 60 heavy atoms: 110 from those with an
aromatic heteroatom or a fused ring system and 40 from the others. Entries
without a downloadable ideal SDF, without coordinates, with more than 200
heavy atoms or with aromatic bond types were dropped. The only change made to
the downloaded files is that two-letter element symbols were re-cased
(`FE` to `Fe`, `CL` to `Cl`), because the SDF reader does not accept the
upper-case form that the CCD writes.

Every CCD file is tested twice if it has formal charges: once with the charges
as given and once with all formal charges set to zero.

### Known problems in the `molecules` files

Not fixed here. In the upstream repository: the fullerenes C20, C24, C26,
C28, C30, C32 and C36 have carbons whose bond orders add up to 3 (C20 and C30
have only single bonds), `coordination/5-square-pyramidal` has a sulfur with
order sum 5, `pyranose/alpha-D-galacturonopyranose` has a carbon with order
sum 3 and `pyranose/alpha-D-glucuronopyranose` an oxygen with order sum 1. The
two pyranose files are not copied here. The double bonds of the C50 to C80
fullerenes (and C60) are not a Fries structure: the C60 file has 18 of its 30
double bonds on pentagon edges.
